# Build the Battlefield: Expanding Sweden’s Cyber-Range with New Attack Scenarios

## Context

A cyber-range is a virtual environment that can be used for testing and training purposes.
For cyber-security in particular, a cyber-range can purposefully expose vulnerabilities.
The [cybercampus in sweden](https://www.cybercampus.se/en) in particular is developping a cyber-range and would benefit from expanding the number and variety of attack scenarios it proposes.


Other tools like [URSID](https://pirat-public.gitlabpages.inria.fr/ursid/) are also proposing the deployment of vulnerable environments and the work on URSID could benefit to enrich the cyber-range of the cyber-campus.
Besides, with the rise of LLM and agentic AI, new vulnerabilities appear and the cyber-range in curently missing scenario exploiting this class of vulnerabilities ([top 10 most exploited vulnerabilities in genAI](https://genai.owasp.org/resource/owasp-genai-llm-top-10-2026/)).
Finally, Active Directory environment are widely used in companies and can introduce some vulnerabilities and misconfigurations (for example ADCS is a recent source of [misconfigurations that can be exploited](https://www.thehacker.recipes/ad/movement/trusts/#%F0%9F%9B%A0%EF%B8%8F-adcs-abuse) as detail in [this blog post series](https://www.own.security/ressources/blog/etat-de-lart-de-la-compromission-dun-environnement-ad-cs-partie-1)) that are not yet part of the cyber-range catalog.

## Project

Improve the cyberrange so that new attack can be played in it.
Depending on students skills and interests this can involve:
- integrate in the cyber-range the list of scenarios available via URSID
- develop new scenarios exploiting vulnerabilities involving AI (agentic or not)
- develop new scenarios exploiting vulnerabilities involving Active Directory
